# opportunity.com

Job search + AI CV builder — single-page app (job feed + CV tailoring).

Design mockup: single-page layout with a search bar, a job feed (left) and a live CV builder (right); dragging a job onto the CV space triggers AI tailoring against the user's saved CV/uploads.

## Stack (planned, mirroring TalentMaroc's CV builder)
- Next.js (App Router), TypeScript
- Supabase: Postgres + Auth (no anonymous sessions) + Storage
- Reused CV template set: Corso, Meridian, Aria, Dahab, Medina, Vertex, Atlas, Lumen, Helix, Slate
